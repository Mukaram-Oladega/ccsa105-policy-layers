## Overview

This repository documents my Check Point Policy Layers practical assignment. It contains my laboratory report and screenshots demonstrating the configuration of policy packages, Ordered Layers, Inline Layers, and policy rulebases using SmartConsole.

## Practical Tasks

- **Task 1:** Inspection of the default Access Control policy and layer properties.
- **Task 2:** Creation of the `Orion-Layers` policy package and `Network` Ordered Layer.
- **Task 3:** Creation and configuration of the `Service-Control` Ordered Layer.
- **Task 4:** Policy installation attempt and assessment of the installation result.
- **Task 5:** Creation of the `DMZ-Policy` Inline Layer.
- **Task 6:** Documentation of Inline Layer testing requirements and expected policy behaviour.
- **Task 7:** Ordered Layer reordering, restoration and sharing configuration.
